訓練說明：並行？最優分數 / 驗證分數是什麼？
  1. 單品種單週期就已經把 CPU 吃滿了

    挖因子這一步計算很重：特徵、公式搜索、回測驗證會把機器算力用到接近滿載。這時再併行開第二個品種或另一個週期，大家只是在搶同一批 CPU，誰也跑不快。

  2. 並行並不等於整體更快

    兩路一起跑，往往各自都變慢，總完工時間通常不比「先訓完一個再訓下一個」更短，有時還更拖。所以默認一次只訓一路，把算力集中用在當前任務上更划算。

  3. 只盯一個品種，更好觀察訓練情況

    曲線、日誌、最優公式都只對應這一組數據，漲沒漲分一眼能看清。多品種並行時頁面和日誌會攪在一起，反而不容易判斷「這個品種還值不值得繼續挖」。

  4. 最優分數是什麼

    到目前為止挖到的最好那條公式的得分。它一般只升不降：一旦發現更好的公式，這個數就會抬一截；長時間不動，說明這段時間還沒挖到更強的。

  5. 驗證分數是什麼

    當前這一步在驗證集上算出來的平均表現，反映「最近這批公式整體好不好」。它會上下波動很正常；更值得看的是整體有沒有慢慢抬高，而不是盯著單次跳動。

  6. 為什麼驗證曲線會一截一截地掉下去再爬起來？

    圖上的驗證分數不是「當前最優那一條」的得分，而是這一步隨機抽出來的一整批公式的平均分。挖著挖著，模型會越來越愛重複同一類公式（探索變少），系統就會主動「攪一攪」——加大隨機、換一批新配方繼續搜。剛攪完時，新配方裡好壞摻半，平均值會突然掉一截；隨後又慢慢學到更好的組合，曲線再往上爬。所以會看到鋸齒狀起伏。

    綠色的最優分數隻記「歷史最好的那一次」，所以不會跟著掉下去，只會階梯往上抬。鋸齒本身多半是在重新探索，不等於訓練壞了。

  7. 重新訓練有機會找出更好的量化因子

    「開始訓練」會接著上次的檢查點繼續挖；「重新訓練」會清掉檢查點，從零換一條隨機路徑再搜一遍。因為搜索帶隨機性，有時能挖到比現在更高的分數。

    已有的最優策略會當作分數下限留著——只有找到更好的才會覆蓋，不會一開局就被弱公式沖掉。代價是要再花一整輪算力，適合本輪訓完或最優分數長期不動時再用。

回測是怎麼算的？（一看就懂）
  1. 先拿歷史行情“假裝交易”

    回測不會真的下單。它把過去很多天的價格拿出來，按策略規則一步步走一遍，看看如果當時真做了，錢會變多還是變少。

  2. 因子先打一個“信號分”

    策略公式會給每一根 K 線打分：正分偏向看漲，負分偏向看跌，靠近 0 就先別亂動。

    分數的絕對值越大，信號就越明確。比如 +3 比 +0.2 更堅決地看漲，-3 比 -0.2 更堅決地看跌。

  3. 信號分越大，倉位就越大

    倉位不是只有“全倉 / 空倉”兩檔，而是用 tanh(信號分) 壓到大約 -1 到 +1 之間。

    • 正分越大 → 做多越多（最多接近滿倉 +1）
    • 負分越小 → 做空越多（最多接近滿倉 -1）
    • 分數很弱 → 倉位接近 0（幾乎不持倉）

    可以把它想成：信心越大，下注越多；但再大也不會超過“一整份倉位”。

  4. 賺虧怎麼算

    這一步大概賺多少 ≈ 倉位 × 價格漲跌。倉位大，漲了賺得多，跌了也虧得多。換倉時還會扣掉你設的手續費和滑點。

  5. 上面那些圖在說什麼
    • 資金曲線：把每一步賺虧累加起來，看帳戶是往上爬還是往下掉。
    • 滾動夏普：看最近一段時間“賺得穩不穩”，越高通常越好。

怎麼看信號？還有哪些要注意
  1. 這張卡怎麼看？（一眼看懂）
    • 先看中間下面那行方向：預期上漲（偏多）或預期下跌（偏空）。顏色也會跟著變——綠偏多、紅偏空。
    • 再看大字把握：策略對這個方向有多堅決——一點把握 → 把握不大 → 一半把握 → 比較有把握 → 很有把握。半環亮得越滿，把握越大。
    • 若顯示「沒把握 / 先觀望」，表示信號太弱，先別當買賣依據。
    • 「因子」是內部算出來的分數，負的偏空、正的偏多，一般不用盯著它；看方向 + 把握就夠了。
    • 這不是「猜對的機率」，只是策略此刻有多堅決。
  2. 只在「當前週期」那根 K 線收盤後才重新判斷

    例如選的是 1 小時週期，就等這一小時走完、K 線正式收盤，才會用最新已收盤的數據重算方向和把握；盤中正在走的那根（未收盤）不會拿來改信號。

  3. 為什麼這樣設計

    訓練和回測用的都是「已經收盤」的完整 K 線。若盤中用還在變動的價格去算，同一根線裡信號會來回跳，也和回測看到的歷史不一致，容易誤判、頻繁改倉。

    等收盤再用完整 OHLC，信號更穩，也和策略當初學到的數據口徑一致。

  4. 相同品種、不同週期，能不能套同一個策略？

    不建議。策略是按訓練時的那個週期學出來的；公式裡的「10 根、20 根」指的是該週期的 K 線根數，不是固定的鐘錶時間。

    例如在 1 小時上訓練時，「10 根」大約看過去 10 小時；若硬套到日線，「10 根」就變成過去 10 天——價格形態、噪聲幅度、趨勢節奏全變了，信號含義對不上，回測成績也推不到新週期上。

    同品種換週期應重新訓練（或至少用該週期單獨回測驗證）；即時監控時，週期盡量與策略文件裡記錄的週期一致。

  5. 卡片上的「距離下次判斷」在倒計什麼

    倒數計時指向下一次收盤、重新判斷信號的時刻。到點後會短暫顯示「即將重新判斷…」，收到新 bar 後再刷新，並開始下一輪倒數計時。
